# craft-handmade (DEFAULT)

带 warm、organic feel 的 hand-drawn 和 paper craft aesthetic。

## Color Palette

- Primary：Warm pastels、soft saturated colors、craft paper tones
- Background：Light cream (#FFF8F0)、textured paper (#F5F0E6)
- Accents：Bold highlights、construction paper colors

## Variants

| Variant | Focus | Visual Emphasis |
|---------|-------|-----------------|
| **Hand-drawn** | Cartoon illustration | Simple icons、略不完美 lines |
| **Paper-cutout** | Layered paper craft | Drop shadows、torn edges、texture |

## Visual Elements

- Hand-drawn 或 cut-paper quality
- Organic、略不完美 shapes
- 用 shadows 表现 layered depth（paper variant）
- Simple cartoon elements 和 icons
- Character illustrations（people、personalities in cartoon form）
- 充足 whitespace，clean composition
- 高亮 keywords 和 core concepts
- **严格 hand-drawn；不要 realistic 或 photographic elements**

## Style Enforcement

- 所有 imagery 必须保持 cartoon/illustrated aesthetic
- 用 hand-drawn equivalents 替代 real photos 或 realistic figures
- 全篇保持一致 line weight 和 illustration style

## Typography

- Hand-drawn 或 casual font style
- 清晰、可读 labels
- Keywords 用更大/更粗 text 强调
- Paper variant 使用 cut-out letter style

## Best For

Educational content、general explanations、friendly infographics、children's content、playful hierarchies
