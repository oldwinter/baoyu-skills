# retro-pop-grid

1970s retro pop art，使用 strict Swiss international grid、thick black outlines 和 flat color blocks。

## Color Palette

- Background：Warm vintage cream/beige (#F5F0E6)
- Flat accents：Salmon pink、sky blue、mustard yellow、mint green，全部为 muted retro tones
- Contrast blocks：策略性使用 solid pure black (#000000) 和 solid pure white (#FFFFFF) 制造 extreme contrast
- Line art and outlines：Solid thick black

## Visual Elements

- 所有 illustrations、text boxes 和 grid dividers 使用 uniform thick black outlines
- Pure 2D flat vector aesthetic，带 subtle screen print texture
- Strict Swiss international grid：poster 由 thick black lines 划分为 square 和 rectangular cells
- 黑底白字 cells 用于 warnings 或 key categories（inverted contrast）
- Empty cells 中使用 geometric fill patterns：checkerboards、diagonal lines、dots
- Flat abstract symbols、warning signs、keyholes、stars、arrows
- 用 vintage comic-style smiley/frowny faces 表示 quality indicators
- Colored cells 用于 breathing room；部分 cell 使用极少或不放内容

## Typography

- Headers：Bold brutalist 或 retro thick display fonts，高可读性
- Body：Clean sans-serif，structured typographic alignment
- Decorative English text 可用于 stylistic labels（"WARNING"、"INFO"、"BEST"）
- 所有 content text 使用指定语言

## Style Enforcement

- 绝对不要 gradients、shading、drop shadows 或 3D effects
- 所有内容都锚定在 grid cells 中；不要 floating 或 unorganized elements
- 保持 1970s retro pop art 和 underground comic illustration feel
- 用 rhythmic grid 平衡 visual density；部分 cells 有意留 sparse 以制造对比

## Avoid

- 3D rendering、realistic details、gradients、soft shadows
- Soft、thin 或 sketch-like pencil lines
- Free-flowing、unorganized 或 floating layouts（所有内容必须 grid-anchored）
- Pure white background canvas
- Organic 或 hand-drawn imperfections

## Best For

Trendy product guides、design-conscious content、visually striking comparisons、面向 design-savvy audiences 的内容、bold social media posts
