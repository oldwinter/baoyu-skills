# retro-popup-pop

Retro pixel popup × pop-art collage：内容渲染为一叠 80/90s desktop dialog windows，使用 thick black outlines、flat color fills，以及 bright cyan 或 vintage cream backgrounds。

## Color Palette

- Background：Bright cyan (#12B8DE) primary canvas，vintage cream (#F5F0E6) alternate
- Window fills：Vintage cream (#F5F0E6) 和 pure white (#FFFFFF)
- Primary text and outlines：Pure black (#000000)
- Reverse text：Solid black title bars 上的 pure white
- Accent fills（仅小面积）：Salmon pink、sky blue、mustard yellow、mint green，均为 muted retro tones

## Visual Elements

- 80s/90s desktop popup windows，带 title bars、close buttons（×）和 chunky borders
- 多个 windows 以 tile 方式排列或轻微重叠，并用 offset solid-black drop shadows 表现 depth
- 用 ERROR / ALERT / WARNING dialogs 高亮 misconceptions、common pitfalls、risks
- File-window vignettes 使用 retro filenames 标注（PROBLEMS.EXE、METHOD.PNG、BURNOUT.PSD、FOCUS_SCAN、SYSTEM_ALERT、IDEAS_MISSING）
- 用 progress bars 表示 completion、difficulty、conversion rate 或 trend
- Pixel-style chunky icons：folders、magnifiers、gears、exclamation marks、floppy disks、hourglasses
- 带 thick black borders 和 short pop-style copy 的 action buttons：OK、CANCEL、FIX IT、SCAN、PLAY、RETRY、SAVE
- Comparison data 渲染为 windowed lists 或 small tabular dialogs
- 每个 window、button、icon 和 divider 都使用 uniform thick black outlines
- 全篇使用 pure 2D flat color fills；不要 gradients、glow、glass

## Typography

- Headers：Pixel / dot-matrix / chunky bitmap display fonts，大号且高对比
- Body：Retro monospace 或 system-style sans-serif，高可读性
- Title bars：solid black 上 reverse white，优先 all-caps
- Decorative all-caps English 可用于 filenames、status strings、button labels（PROBLEMS.EXE、OK、CANCEL）；body content text 使用已确认输出语言

## Style Enforcement

- 每个 information chunk 都必须位于 window、dialog、button 或 progress bar 中；不要 floating elements
- 各处使用 uniform thick black outlines；用 offset solid-black drop shadows 表现 stacked-window depth
- 每个 composition 的 accent palette 限制在约 4 种颜色；让 cyan 或 cream 主导 canvas
- 保持 low-fi pixel/popup feel；欢迎 humorous popup copy，禁止 polished modern UI

## Avoid

- Modern UI styles：glassmorphism、neumorphism、soft shadows、blurs、gradients
- 3D rendering、photorealism、ray-traced shadows
- Hand-drawn wobble、watercolor washes 或 sketch textures
- Icons 上的 smooth anti-aliased curves（优先 chunky pixel/stair-step edges）
- Pure black backgrounds；保持 cyan 或 cream 作为 canvas

## Best For

High-density "干货" knowledge guides、common-pitfall and debunking posts、面向 design-savvy 或 developer audiences 的 knowledge-pop content、Xiaohongshu-style retro-tech posts、dense-modules portrait infographics。
