# morandi-journal

使用 warm Morandi color tones 和 cozy bullet journal aesthetic 的 hand-drawn doodle illustration。

## Color Palette

- Background：Warm cream/beige，带 subtle paper texture (#F5F0E6)
- Primary：Muted teal/sage green (#7BA3A8)，用于 headers 和 frames
- Secondary：Warm terracotta/orange (#D4956A)，用于 highlights 和 numbers
- Line art：Dark charcoal brown (#4A4540)
- Soft highlights：Pale yellow (#F5E6C8)

## Visual Elements

- Hand-drawn doodle illustrations，使用 organic、略不完美 ink lines
- Washi tape strip decorations（diagonal stripes pattern，beige and brown）
- 用于 brand/option items 的 rounded card containers
- 带 emoji quality indicators 的 hand-drawn rulers、scales 和 progress bars
- 用 smiley/frowny faces 作为 quality markers（😊✓ 😐 ☹️✗）
- Sections 周围使用 dotted line frames
- Modules 之间使用 connecting arrows 和 dotted lines
- Corner decorations：tiny houses、stars、sparkles、clouds
- Sections 之间使用 wavy line dividers
- 用于 tips 的 callout bubbles
- 用于 identification tips 的 magnifying glass icons
- Thumbs up/down icons（hand-drawn style）

## Variants

| Variant | Focus | Visual Emphasis |
|---------|-------|-----------------|
| **Cozy journal** | Maximum warmth | 更多 washi tape、stickers、decorative doodles |
| **Clean sketch** | Readability | 更干净 lines、更少 decoration、更 structured |

## Typography

- Main title：Bold hand-lettered calligraphy style，带 decorative flourishes
- Module headers：dark teal rounded badge (#6B9080) 上的白色 clean handwritten text
- Body text：整洁 handwritten print style，易读
- Numbers：用 terracotta (#D4956A) 高亮，略大于 body

## Style Enforcement

- 所有 imagery 必须保持 hand-drawn/doodle aesthetic；不要 digital precision
- 全篇使用 organic、略不完美 shapes
- Sketch-like quality，带 visible line weight variations
- Warm and cozy journal feel，不要 clinical 或 corporate

## Avoid

- Flat vector icons 或 emoji
- Clean geometric shapes
- Stock illustration style
- Strict grid layout
- Pure white background
- Digital/corporate look

## Best For

Product selection guides、lifestyle content、educational overviews、consumer-facing comparison content、Xiaohongshu-style posts
