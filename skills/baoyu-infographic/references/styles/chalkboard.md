# chalkboard

黑色 chalkboard background，搭配彩色 chalk drawing style

## Design Aesthetic

Classic classroom chalkboard aesthetic，搭配 hand-drawn chalk illustrations。带 nostalgic educational feel，使用 imperfect、sketchy lines 捕捉传统教学的温度。彩色 chalk 创建 visual hierarchy，同时保持 authentic chalkboard experience。

## Background

- Color：Chalkboard Black (#1A1A1A) 或 Dark Green-Black (#1C2B1C)
- Texture：Realistic chalkboard texture，带 subtle scratches、dust particles 和 faint eraser marks

## Typography

Hand-drawn chalk lettering style，带 visible chalk texture。不完美 baseline 增加真实感。使用 white 或 bright colored chalk 强调。

## Visual Elements

- 使用 sketchy、imperfect lines 的 hand-drawn chalk illustrations
- text 和 key elements 周围添加 chalk dust effects
- Doodles：stars、arrows、underlines、circles、checkmarks
- Mathematical formulas 和 simple diagrams
- Eraser smudges 和 chalk residue textures
- Wooden frame border 可选
- Stick figures 和 simple icons
- 带 hand-drawn feel 的 connection lines

## Style Rules

### Do

- 所有元素保持 authentic chalk texture
- 全篇使用 imperfect、hand-drawn quality
- 添加 subtle chalk dust 和 smudge effects
- 用 color variety 创建 visual hierarchy
- 包含 playful doodles 和 annotations

### Don't

- 使用 perfect geometric shapes
- 创建 clean digital-looking lines
- 添加 photorealistic elements
- 使用 gradients 或 glossy effects

## Best For

Educational content、tutorials、classroom themes、teaching materials、workshops、informal learning sessions、knowledge sharing
