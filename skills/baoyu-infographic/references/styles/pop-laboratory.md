# pop-laboratory

Lab manual precision 与 pop art color impact 结合，在 blueprint grid 上使用 coordinate systems、technical diagrams 和 fluorescent accents。

## Color Palette

- Background：Professional grayish-white，带 faint blueprint grid texture (#F2F2F2)
- Primary：Muted teal/sage green (#B8D8BE)，用于 major functional blocks 和 data zones
- High-alert accent：Vibrant fluorescent pink (#E91E63)，严格用于 warnings、critical data 或 "winner" highlights
- Marker highlights：Vivid lemon yellow (#FFF200)，作为 keywords 的 translucent highlighter effect
- Line art：Ultra-fine charcoal brown (#2D2926)，用于 technical grids、coordinates 和 hairlines

## Visual Elements

- 每个 module 都有 coordinate-style labels（如 R-20、G-02、SEC-08）
- Technical diagrams：exploded views、带 anchor points 的 cross-sections、architectural skeletal lines
- 带 precise markers（0.5mm、1.8mm、45°）的 vertical/horizontal rulers
- "Marker-over-print" effect：color blocks 相对 text 略微偏移，形成 postmodern print feel
- Cross-hair targets、mathematical symbols（Σ、Δ、∞）、directional arrows（X/Y axis）
- Microscopic detail annotations 搭配 macroscopic bold headers
- Corner metadata：tiny barcodes、timestamps、technical parameters
- Massive bold headers 与 tiny 8pt-style annotations 形成高对比

## Typography

- Headers：Bold brutalist characters，高 visual impact
- Body：Professional sans-serif 或 crisp technical print
- Numbers：大号，并用 yellow 或 blue 高亮以突出
- Annotations：Ultra-crisp，小号 technical labels

## Style Enforcement

- 严格系统化使用颜色：只用 teal、pink、yellow、charcoal；不要 rainbow palette
- 全篇保留足够 fine grid lines 和 coordinate annotations
- 保持 large impactful headers 与 small precise parameters 之间的 tension
- Lab manual aesthetic：混合 microscopic details 和 macroscopic data

## Avoid

- Cute 或 cartoonish doodles
- Soft pastels 或 generic textures
- Empty white space
- Flat vector stock icons
- Organic 或 hand-drawn imperfections

## Best For

Technical product guides、specification comparisons、precision-focused data visualization、engineering-adjacent content
