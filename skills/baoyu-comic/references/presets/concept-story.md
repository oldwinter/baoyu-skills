# concept-story

概念故事预设 - 通过角色驱动故事可视化抽象概念的 narrative comics

## Base Configuration

| 维度 | 值 |
|-----------|-------|
| Art Style | manga |
| Tone | warm |
| Layout | standard (default) |

等价于：`--art manga --tone warm`

## Unique Rules

此 preset 包含超出 art+tone 组合的特殊规则。使用 `--style concept-story` 时，必须应用下方所有规则。

### Concept Visualization System (CRITICAL)

每个主要抽象概念都应该有一个反复出现的视觉符号/metaphor：

| 概念类型 | 可视化方式 |
|-------------|----------------------|
| Psychological need | 角色持有或发现的实体对象（例如发光能量球 = competence） |
| Management principle | 角色穿行其中的环境 metaphor（例如船舵 = autonomy） |
| Growth/development | 会变化的生命/有机符号（例如种子 → 开花植物 = relatedness） |
| Abstract framework | 角色可以进入或观察的空间结构 |
| Emotional state | 场景氛围中的色彩/光照变化 |

**不同于 ohmsha**：允许且期待使用 dialogue panels。目标是把 visual metaphors 与 dialogue 结合，而不是完全替代 dialogue。

**模式**："Dialogue introduces idea" → "Visual metaphor illustrates it" → "Character reacts/applies it"

### Visual Symbol Continuity

符号必须贯穿整个故事：

| 阶段 | 处理 |
|-------|-----------|
| Introduction | 概念首次被提到时，符号带 soft glow effect 出现 |
| Recurrence | 概念再次被引用时，同一符号在背景或角色互动中再次出现 |
| Resolution | 所有符号汇聚在最终构图中，展示已学概念的整合 |

**Storyboard 要求**：在 panel breakdown 前加入 Symbol Mapping Table，定义 concept → visual symbol。

### Character Archetypes (Flexible)

根据内容领域创建原创角色。没有固定默认角色：

| 角色 | Archetype | 视觉线索 |
|------|-----------|------------|
| Protagonist | 面对挑战的学习者/工作者 | 现代专业人士或学生，有 relatable 感，起初姿态受限 |
| Mentor | 通过经验教学的资深向导 | 略年长，气质平静，暖色强调 |
| Catalyst | 触发转变的人或事件 | 可以是同事、情境、挑战或机会 |

**重要**：每次都根据 source content 的领域（business、psychology、education 等）重新创建角色。没有默认角色集。

### Narrative Arc Structure

执行五阶段成长弧线：

| Act | 结构 | 视觉基调 |
|-----|-----------|------------|
| Opening | Protagonist 困在日常中，面对挫败 | 柔化暖色调、紧 framing、受限构图 |
| Inciting moment | Mentor 出现或机会到来 | 亮度提升，panels 打开 |
| Learning | 通过 visual metaphors 引入概念 | 丰富暖色调色板，符号逐个出现 |
| Turning point | Protagonist 应用知识并面对测试 | 对比增强，动态构图 |
| Transformation | 展示成长，可见新的理解 | 完整暖色调色板，开阔构图，所有符号出现 |

### Dialogue + Action Balance

- 鼓励且期待 dialogue（不同于 ohmsha 的 NO talking heads 规则）
- 每页应至少包含一个 dialogue panel 和一个 visual/action panel
- 避免纯“讲课”页面，即一个角色连续 4+ panels 解释
- 当角色口头解释概念时，下一格 panel 应该将其可视化

**错误方式**：mentor 连续四格对 protagonist 讲课
**正确方式**：mentor 引入概念 → visual metaphor panel → protagonist 反应 → 应用理解

### Scene Atmosphere Rules

| 场景类型 | 氛围 |
|------------|-----------|
| Problem/frustration | 暖底上叠加冷 muted tones，紧 framing，杂乱环境 |
| Mentoring moment | Golden hour lighting，开放构图，温暖室内 glow |
| Concept visualization | Soft glow effects，干净简化背景，符号 spotlight |
| Growth/transformation | 暖光向外扩展，角色姿态打开 |
| Resolution | 完整暖色调色板，宽敞构图，所有视觉符号可见 |

### Ending Requirements

最终页必须包含：

1. Protagonist 展示转变后的理解（不是只被告知）
2. Visual callback 展示与开场状态的对比（例如枯萎植物 → 繁茂植物）
3. 所有概念符号在构图中同时可见
4. 一个面向未来的元素，暗示持续成长（不是封闭结局）

### Page Title Convention

每页都必须有叙事标题：

**Wrong**: "Chapter 3: Self-Determination Theory"
**Right**: "The Day Xiao Ming Found His Own Engine"

## Quality Markers

- ✓ 每个主要概念都有反复出现的视觉符号
- ✓ Dialogue 与 visual metaphors 协同工作（不是一个替代另一个）
- ✓ 从问题到转变的清晰成长弧线
- ✓ 原创角色适配内容领域
- ✓ 全程温暖、专业的氛围
- ✓ 视觉符号在故事中反复出现并逐步累积
- ✓ 最终页整合所有概念符号，并有 transformation callback

## Best For

心理学概念、商业/管理原则、动机理论、个人发展、
self-help 内容、领导力框架、coaching narratives、软技能教育、
通过角色驱动故事解释抽象概念
