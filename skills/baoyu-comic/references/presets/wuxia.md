# wuxia

武侠预设 - Hong Kong martial arts comic style

## Base Configuration

| 维度 | 值 |
|-----------|-------|
| Art Style | ink-brush |
| Tone | action |
| Layout | splash (default) |

等价于：`--art ink-brush --tone action`

## Unique Rules

此 preset 包含超出 art+tone 组合的特殊规则。使用 `--style wuxia` 时，必须应用下方所有规则。

### Qi/Energy Effects (Required)

武术力量必须通过 qi effects 可见：

| Effect Type | 视觉处理 |
|-------------|-----------------|
| Internal qi | 角色周围有发光 aura |
| External qi | 可见能量投射 |
| Qi clash | 放射状 impact waves |
| Qi absorption | 粒子流向角色 |
| Hidden power | 眼睛/拳头有细微 glow |

### Energy Colors

| Qi Type | 颜色 |
|---------|-------|
| Righteous | Blue (#4299E1), Gold (#FFD700) |
| Fierce | Red (#DC2626), Orange (#EA580C) |
| Evil | Purple (#7C3AED), Green (#16A34A) |
| Pure | White, Silver |
| Ancient | Gold with particles |

### Combat Visual Language

**Impact moments** 必须包含：

1. 从冲击点放射出的 speed lines
2. 飞散 debris（石头、木头、布料）
3. Shockwave rings
4. 尘土/能量云
5. 头发和衣物被吹向后方

### Movement Depiction

| 速度级别 | 视觉处理 |
|-------------|-----------------|
| Normal | 标准姿势 |
| Fast | Motion blur、speed lines |
| Lightning | Afterimages、多重位置 |
| Teleport | Fade effect、粒子轨迹 |

### Environmental Integration

背景必须支持动作：

| 环境 | 战斗增强 |
|-------------|-------------------|
| Mountains | 冲击造成山峰崩裂 |
| Forest | 树木炸裂、叶片飞散 |
| Water | 戏剧化水花、水上行走 |
| Temple | 柱子碎裂、瓦片飞散 |
| Cliff | 戏剧化坠落、风效 |

### Character Pose Guidelines

- 带重心分布的动态武者架势
- 流动长袍和头发表现运动
- 动作中可见肌肉张力
- 双脚扎稳或处于动态运动
- 传统武术姿态

### Weapon Effects

| 武器 | 视觉处理 |
|--------|-----------------|
| Sword | 拖尾光弧、剑身 glow |
| Palm | Qi projection、风效 |
| Staff | 旋转 blur、冲击涟漪 |
| Whip | 流动能量轨迹 |

### Atmospheric Elements

始终包含：
- 飘浮粒子（叶片、花瓣、尘土）
- 用于深度的 ink wash mist
- 风向指示
- 适当时使用戏剧化天空/天气

## Quality Markers

- ✓ 带运动感的动态动作姿势
- ✓ 线条中有 ink brush 美学
- ✓ 可见 qi/energy effects
- ✓ 高对比戏剧光照
- ✓ 带 Chinese elements 的氛围背景
- ✓ 织物和头发有流动运动
- ✓ 有冲击力的战斗时刻
- ✓ Speed lines 和 impact effects

## Best For

武术故事、中国历史小说、wuxia/xianxia 改编、动作密集叙事
