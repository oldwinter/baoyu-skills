# shoujo

少女预设 - 带浪漫美学的 classic shoujo manga

## Base Configuration

| 维度 | 值 |
|-----------|-------|
| Art Style | manga |
| Tone | romantic |
| Layout | standard (default) |

等价于：`--art manga --tone romantic`

## Unique Rules

此 preset 包含超出 art+tone 组合的特殊规则。使用 `--style shoujo` 时，必须应用下方所有规则。

### Decorative Elements (Required)

每个情绪时刻都必须包含装饰元素：

| 情绪 | 必需装饰 |
|---------|---------------------|
| Love | 飘浮爱心、闪光、玫瑰花瓣 |
| Longing | 羽毛、气泡、远处闪光 |
| Joy | 花朵绽放、光爆、星星 |
| Sadness | 飘落花瓣、逐渐消散的闪光 |
| Shyness | 柔和闪光、飘浮气泡 |
| Realization | 带闪光的放射线 |

### Eye Detail Requirements

眼睛在 shoujo style 中至关重要：

| 方面 | 处理 |
|--------|-----------|
| Size | 大于标准 manga（1.2x） |
| Highlights | 多个（3-5 个），按情绪放置 |
| Reflection | 情绪时刻中有场景倒影 |
| Sparkle | 内置 sparkle effects |
| Tears | 水晶般、细节丰富的泪滴 |

### Character Beauty Standards

| 特征 | 处理 |
|---------|-----------|
| Hair | 流动、细致发束、光泽高光 |
| Skin | 瓷白，脸颊柔和 blush |
| Lips | 柔软、微微 glossy |
| Hands | 优雅、有表现力的手势 |
| Posture | 优美、优雅的姿势 |

### Background Effects

**Abstract backgrounds** for emotional moments:

| 时刻类型 | 背景 |
|-------------|-----------|
| Love confession | 柔和渐变 + 飘浮花朵 |
| Shock | Screen tone speed lines + sparkles |
| Memory | 梦幻 blur + 散落花瓣 |
| Realization | 放射线 + light burst |
| Intimate | Soft focus + 飘浮元素 |

### Panel Flow

- 亲密时刻使用重叠 panels
- 为情绪冲击打破 panel 边界
- 让装饰元素飘浮在 panels 之间
- 用 screen tone gradients 营造情绪
- 用不规则 panel 形状制造 drama

### Emotional Beat Timing

放慢节奏以增强情绪冲击：

| 场景类型 | Panel 处理 |
|------------|-----------------|
| Confession | 多个小 panels，然后 splash |
| Eye contact | Close-up sequence |
| Touch | Slow-motion panel breakdown |
| Realization | 先 build-up panels，再冲击 |

### Color Palette Application

| 场景类型 | Palette |
|------------|---------|
| Romantic | Pink, lavender, rose gold |
| Happy | Soft yellow, peach, sky blue |
| Sad | Pale blue, silver, gray lavender |
| Dramatic | Deep rose, purple, contrast |

### Screen Tone Usage

| Mood | Tone Pattern |
|------|-------------|
| Neutral | 干净、极简 |
| Romantic | 柔和渐变叠层 |
| Dramatic | 高对比 tones |
| Dreamy | 柔和圆点图案 |

## Quality Markers

- ✓ 大而闪亮、细节丰富的眼睛
- ✓ 情绪时刻有装饰元素
- ✓ 流动、美丽的角色设计
- ✓ 柔和 pastel 调色板
- ✓ 优雅 panel 构图
- ✓ Screen tone 情绪效果
- ✓ 全程浪漫氛围
- ✓ 美丽、有表现力的姿势

## Best For

浪漫故事、成长故事、友谊叙事、校园生活、情感 drama、爱情故事
