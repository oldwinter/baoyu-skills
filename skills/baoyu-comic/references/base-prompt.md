## 图片规格

- **Type**：多 panel 漫画页
- **Orientation**：Portrait（竖版）
- **Aspect Ratio**：2:3
- **Style**：视觉准则见对应 style reference

## Panel 结构

### Panel 边框
- 每个 panel 周围使用干净的黑色线条（1-2px）
- panel 之间留白色 gutter（8-12px）
- panel 排布要形成清晰阅读动线
- panel 尺寸要有变化，形成视觉节奏

### Panel 构图
- 每个 panel 都要有清晰焦点
- 合理使用 foreground、midground、background
- 镜头角度要有变化：eye level、bird's eye、low angle、close-up、wide shot
- 动作在 panel 之间要逻辑连贯
- 有意识地使用 negative space

## 文本元素

### Speech Bubbles
- **Dialogue**：椭圆形气泡，带尖尾
- 白色填充，细黑描边
- 气泡尾巴要明确指向说话者
- 使用手写 lettering 风格字体（不要像电脑生成）

### Narrator Boxes
- **Fourth Wall/Narrator**：矩形框
- 通常放在 panel 边缘（顶部或底部）
- 使用略有区分的填充色（cream 或 light yellow）
- 用于评论、时间跳转、解释

### Thought Bubbles
- 云朵形状，并用小气泡轨迹连到思考者
- 轮廓比 speech bubbles 更柔和
- 用于内心独白

### Caption Bars
- 位于 panel 边缘的矩形条
- 展示时间与地点信息
- 用于 "Meanwhile..."、"Three years later..." 这类转场
- 深色填充白字，或反过来

### Typography
- 全篇保持手绘 lettering 风格
- 重点和 key terms 使用 bold
- 字号保持一致
- 中文文本：使用中文全角标点 ""，。！
- 层级清晰：titles > dialogue > captions

## 科学 / 概念可视化

描绘抽象概念时：

| 概念 | 视觉隐喻 |
|---------|----------------|
| Neural networks | 发光节点，由干净线条连接 |
| Data flow | 沿简单路径移动的发光粒子 |
| Algorithms | 几何图案、building blocks |
| Logic/proof | 互锁的 puzzle pieces |
| Discovery | 穿透黑暗的光 |
| Uncertainty | 分叉路径、问号 |
| Time | 时钟母题、日历页 |

- 将 diagrams 自然融入叙事 panel
- 解释内容使用 inset panels 或 thought-bubble 风格
- 优先使用简化 iconography，而不是写实描绘

## Fourth Wall / Narrator Character

描绘面向读者说话的 narrator characters 时：
- 角色可以直接看向 panel 外
- 可以出现在 "present day" 框架场景中
- 与主时间线使用有区别的视觉处理
- 通常位于页面边缘或专用 panel 中
- 可以评论或追问画面中的事件

## 历史准确性

- 研究特定时代细节：服装、技术、建筑
- 跨时间段呈现角色时，要自然表现年龄变化
- 标志性物品和地点要画得可识别
- 在准确性与 stylization 之间保持平衡
