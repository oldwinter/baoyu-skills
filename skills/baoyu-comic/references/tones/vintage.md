# vintage

复古基调 - 历史感、旧化、时代真实性

## Overview

带旧纸效果和符合时代美学的历史氛围。创造时间感、真实性和历史距离感。

## Mood Characteristics

- 历史真实性
- 时代距离
- 档案质感
- 时间与记忆
- 古典优雅

## Color Modifiers

应用到任意 art style 时：

| 调整 | 方向 |
|------------|-----------|
| Saturation | 降低、柔化 |
| Contrast | 中等、旧化 |
| Temperature | 偏 sepia |
| Brightness | 轻微褪色 |

## Color Palette

转向旧化色调：

| 角色 | 颜色 | Hex |
|------|-------|-----|
| Primary | Sepia brown | #8B7355 |
| Background | Aged paper | #F5E6D3 |
| Accent 1 | Faded teal | #6B8E8E |
| Accent 2 | Muted burgundy | #7B3F3F |
| Ink | Aged black | #3D3D3D |
| Yellowed | Paper yellow | #F5DEB3 |

## Visual Effects

**Aging effects** (apply subtly):

| Effect | 应用 |
|--------|-------------|
| Paper aging | 背景纹理 |
| Faded edges | Vignette effect |
| Dust specks | 细微叠层 |
| Yellowing | 色彩偏移 |
| Wear marks | 角落/边缘细节 |

## Period Elements

- Historical typography
- 时代准确细节
- 档案式呈现
- 古典构图
- 正式 framing

## Lighting

- 自然、符合时代
- 油灯/烛光温暖感
- 柔和漫射光
- 室内历史光照
- 摄影质感

## Emotional Range

| 情绪 | 表达 |
|---------|-----------|
| Dignity | 正式、沉着 |
| Sorrow | 克制、优雅 |
| Pride | 古典姿态 |
| Wisdom | 历经岁月的从容 |

## Composition

- 古典 framing
- 正式构图
- 符合时代的 staging
- Documentary style
- 历史准确性优先

## Best For

- 1950 年代前的故事
- 古典科学史
- 历史传记
- 时代作品
- Documentary comics
- 档案叙事

## Combination Notes

特别适合搭配：
- realistic：时代剧
- ligne-claire：历史冒险
- ink-brush：古典亚洲故事

避免搭配：
- manga：风格不匹配（过于现代）
- chalk：风格不匹配（现代教育感）
