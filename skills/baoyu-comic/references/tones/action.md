# action

动作基调 - 速度、冲击、力量

## Overview

高冲击动作氛围，包含动态运动、战斗效果和强视觉能量。创造直观、刺激的 sequence。

## Mood Characteristics

- 速度与运动
- 力量与冲击
- 战斗强度
- 身体能量
- 直观刺激

## Color Modifiers

应用到任意 art style 时：

| 调整 | 方向 |
|------------|-----------|
| Saturation | 高对比 |
| Contrast | 最大 |
| Temperature | 随效果变化 |
| Brightness | 动态范围 |

## Action Effects

**Combat/motion effects** (apply liberally):

| Effect | 用途 |
|--------|-------|
| Speed lines | 运动、速度 |
| Impact bursts | 打击、碰撞 |
| Shockwaves | 强力冲击 |
| Flying debris | 环境破坏 |
| Dust clouds | 地面冲击 |
| Motion blur | 快速运动 |
| Afterimages | 超高速 |

## Special Effects

| Effect Type | 视觉方式 |
|------------|-----------------|
| Energy attacks | 发光、放射 |
| Physical impacts | 放射线、碎片 |
| Movement | Speed lines、blur |
| Atmosphere | 飞散粒子、风 |

## Effect Colors

| Effect | 颜色 | Hex |
|--------|-------|-----|

| Fire/power | Gold | #FFD700 |

## Lighting

- 动态、变化
- 冲击闪光

- 人物 rim lighting
- 戏剧化对比

## Emotional Range

| 情绪 | 表达 |
|---------|-----------|
| Determination | 凶猛专注 |
| Rage | 强烈、有力量 |
| Triumph | 胜利姿态 |
| Struggle | 用力挣扎 |

## Composition

- 动态角度
- 极端透视
- 破 panel 布局
- 非对称设计
- 以冲击为中心的 framing

## Pose Guidelines

- 动态战士姿势
- 可见重量和动量
- 展示肌肉张力
- 捕捉运动流向
- 强调冲击点

## Best For

- 武术战斗
- 动作 sequences
- 运动时刻
- 身体挑战
- 战斗场景
- 高潮对峙

## Combination Notes

特别适合搭配：
- ink-brush：武侠战斗
- manga：shonen battles

避免搭配：
- chalk：风格不匹配
- ligne-claire：风格不匹配（过于静态）
