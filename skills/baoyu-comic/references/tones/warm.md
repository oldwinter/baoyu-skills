# warm

温馨基调 - 怀旧、个人化、安慰感

## Overview

适合个人故事和怀旧内容的温暖、亲切氛围。通过舒适美学和安慰感视觉建立情感连接。

## Mood Characteristics

- 怀旧感
- 个人化、亲密氛围
- 安慰与疗愈
- 记忆与反思
- 温柔的情感温度

## Color Modifiers

应用到任意 art style 时：

| 调整 | 方向 |
|------------|-----------|
| Saturation | 略微降低 |
| Contrast | 更柔软 |
| Temperature | 向暖色偏移（+15%） |
| Brightness | 柔和、金色 |

## Color Temperature

Shift palette toward warm tones:

| 原色 | 暖色偏移 |
|----------|-----------|
| Cool blue | Soft teal |
| Pure white | Cream |
| Gray | Warm gray |
| Black | Soft charcoal |

## Accent Colors

- Golden yellow (#D69E2E)
- Soft orange (#DD6B20)
- Warm brown (#8B6F47)
- Sunset tones

## Lighting

- Golden hour lighting
- 柔和漫射光
- 温暖室内 glow
- 蜡烛/灯光温暖感
- 温柔阴影

## Emotional Range

| 情绪 | 表达 |
|---------|-----------|
| Joy | 真诚温暖的微笑 |
| Sadness | 温柔忧伤 |
| Love | 柔软、温情表情 |
| Memory | 遥远、沉思的凝视 |

## Composition

- 亲密 framing
- 舒适环境
- Soft focus 背景
- 有欢迎感的空间
- 突出个人时刻

## Visual Elements

- 暖光光线
- 柔软边缘
- 怀旧道具（旧照片、纪念物）
- 舒适物件（毯子、茶杯）
- 自然元素（秋叶、日落）

## Best For

- 个人故事
- 童年回忆
- 导师叙事
- 家族历史
- 温柔传记
- 疗愈旅程

## Combination Notes

特别适合搭配：
