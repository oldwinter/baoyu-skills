# neutral

中性基调 - 平衡、理性、教育

## Overview

默认平衡 tone，适合教育和信息类内容。既不过度情绪化，也不冰冷，营造易接近且专业的氛围。

## Mood Characteristics

- 平衡的情绪语域
- 清晰、理性的呈现
- 聚焦教育
- 专业但亲近
- 客观叙事

## Color Modifiers

应用到任意 art style 时：

| 调整 | 方向 |
|------------|-----------|
| Saturation | 标准（不偏移） |
| Contrast | 平衡 |
| Temperature | 中性 |
| Brightness | 略明亮 |

## Lighting

- 均匀清晰光照
- 极少戏剧化阴影
- 跨 panels 保持一致
- 自然光源
- 无极端对比

## Emotional Range

| 情绪 | 表达程度 |
|---------|-----------------|
| Joy | 适度微笑 |
| Concern | 思考表情 |
| Surprise | 眼睛轻微睁大 |
| Frustration | 轻微皱眉 |

## Composition

- 平衡 panel 布局
- 清晰焦点
- 可读层级
- 标准 framing
- 功能性构图

## Best For

- 教育内容
- 技术教程
- 信息型传记
- Documentary style
- 专业主题

## Usage Notes

Neutral 是默认 tone。可与任意 art style 组合，产出基准专业结果。它是最通用的 tone 选项。
