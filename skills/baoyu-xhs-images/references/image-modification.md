# 图片修改

| Action | 做法 |
|--------|-----|
| Edit | **先**更新 `prompts/NN-{type}-{slug}.md`，再用同一个 session ID 重新生成 |
| Add | 指定插入位置 → 创建 prompt → 生成 → 后续文件重新编号 `NN+1` → 更新 outline |
| Delete | 删除文件 → 后续文件重新编号 `NN-1` → 更新 outline |

重新生成前始终先更新 prompt 文件 —— 它是唯一真源，也让改动可复现。

文字修正策略：

- 如果某张卡片的标题、正文、标签或任何其他渲染文字出现拼错、乱码、难以辨认或视觉表现偏弱，不要用代码去修补 bitmap。
- 需要修正文字而重新生成时，写新的 prompt 文件并使用新的输出路径，以便保留有问题的候选图用于对比。
- 后处理只限裁剪、缩放、压缩或格式转换，且不得改变文字或主构图。
