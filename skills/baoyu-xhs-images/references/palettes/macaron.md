# Macaron Palette

暖奶油背景上的柔和 pastel 色块。整体温和、亲近，并带有教育感。

## 背景

- 颜色：Warm cream (#F5F0E8)
- 纹理：细微纸张颗粒，暖色调

## 颜色

| 角色 | 颜色 | Hex | 用途 |
|------|-------|-----|-------|
| Background | Warm Cream | #F5F0E8 | 主背景 |
| Text | Deep Charcoal | #2C3E50 | 标题、主要内容 |
| Secondary Text | Warm Gray | #6B6B6B | 注释、标签 |
| Block Color | Macaron Blue | #A8D8EA | 内容块填充 |
| Block Color | Macaron Lavender | #D5C6E0 | 内容块填充 |
| Block Color | Macaron Mint | #B5E5CF | 内容块填充 |
| Block Color | Macaron Peach | #F8D5C4 | 内容块填充 |
| Accent | Coral Red | #E8655A | 强调、高光 |

## 语义约束

柔和 pastel macaron 调色板。使用块状颜色作为圆角 card 背景，用于区分信息分区。Coral red 强调色应克制使用，只用于强调关键词。所有颜色都应温和、亲近，不使用饱和色或 neon 色。不要把颜色名称或角色标签渲染为图片中的可见文本。

## 最佳搭配

- `sketch-notes`，天然适合手绘教育内容
- `notion`，macaron 强调色能柔化 monochrome 美学
- `chalkboard`，pastel 粉笔色替代标准粉笔色
- `warm`，强化舒适友好的感受
- `fresh`，补充干净自然的美学
