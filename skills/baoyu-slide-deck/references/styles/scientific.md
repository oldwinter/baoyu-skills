# scientific

用于 pathways、processes 和 technical diagrams 的 educational scientific illustration style

## Design Aesthetic

Academic scientific illustration aesthetic，适用于 biological pathways、chemical processes 和 technical systems。Clean、precise diagrams，带 proper labeling 和 clear visual flow。Educational clarity 搭配 professional polish。想象 textbook quality illustrations 和 academic journal figures。

## Background

- Color: Off-White (#FAFAFA) 或 Light Blue-Gray (#F0F4F8)
- Texture: 无，或使用 very subtle paper grain 营造 print feel

## Typography

### Primary Font (Headlines)

使用 clean serif font（Times New Roman style）营造 formal academic feel。Main titles 使用 bold weight。Professional、authoritative presence。

### Secondary Font (Labels)

Diagram labels 和 annotations 使用 sans-serif。小尺寸下清晰可读。用 consistent sizing 建立 hierarchy。

### Body Font

Body paragraphs 使用 serif，bullet points 和 lists 使用 sans-serif。Academic publication styling。

## Visual Elements

- Horizontal membrane 或 structure bases
- 带 distinct colors 的 labeled modular components
- Flow arrows（electron、proton、molecule movement）
- Chemical formulas 和 molecular notation
- Cross-section 和 pathway diagrams
- Numbered step sequences
- Key molecule callouts
- Process summary boxes

## Style Rules

### Do

- 使用 precise、consistent line weights
- 清晰标注所有 components
- 用 arrows 表示 directional flow
- 在相关处包含 chemical/molecular notation
- 创建清晰 numbered sequences

### Don't

- 使用 decorative illustrations
- 创建不精确或过度 artistic 的 diagrams
- 省略重要 labels
- 使用不一致 visual language
- 添加 slide numbers、footers 或 logos

## Best For

Biology lectures、chemistry presentations、medical education、research presentations、academic papers、scientific conferences、textbook illustrations、process documentation
