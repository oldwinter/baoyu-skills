# intuition-machine

带 aged paper texture 和 bilingual explanatory text boxes 的 technical briefing infographic style

## Design Aesthetic

Academic/technical briefing presentation style，不是 artistic 3D renders。Clean 2D 或 isometric technical illustrations，搭配多个包含 article content 的 explanatory text boxes。Split layouts：visuals 位于左侧/中间，text 位于右侧/底部。Information-dense 但 organized，并有清晰 visual hierarchy。Vintage blueprint aesthetic，带 modern clarity。

## Background

- Color: Aged Cream (#F5F0E6)
- Texture: Subtle paper texture，带 light creases，以及让人联想到 vintage technical prints 的 warm nostalgic feel

## Typography

### Primary Font (Headlines)

使用 dark maroon 的 bold display font，main titles 用括号包裹并 ALL CAPS。下方放较小 English subtitle。Technical、authoritative presence，带 vintage character。

### Secondary Font (Labels)

Bilingual callout labels 使用 clean sans-serif。格式："ENGLISH TERM 中文翻译"。与 background 高对比。

### Body Font

Text box content 使用 clean geometric sans-serif。小尺寸下可读。全篇 weight 一致。

## Visual Elements

- Isometric 3D technical illustrations 或 flat 2D diagrams（根据 concept 选择）
- 每张 slide 包含 3-5 个 explanatory text boxes，并有 labeled content
- 指向 key parts 的 bilingual callout labels
- Faded thematic background patterns（与 topic 相关的 circuits、gears、flowcharts）
- 所有元素使用 clean black outlines
- Split 或 triptych layouts
- 底部放 "KEY QUOTE:" box，包含 core insight
- 角落不要放 title blocks、stamps 或 watermarks

## Style Rules

### Do

- 包含 3-5 个 text boxes，放入来自 source material 的 substantive content
- 对 key elements 使用 bilingual labels（English + Chinese）
- 添加与 topic 相关的 faded thematic background patterns
- 全篇保持 aged paper texture
- 用 split layouts 创建清晰 visual hierarchy

### Don't

- 创建 photorealistic renders 或 artistic 3D scenes
- 让 slides 缺少 explanatory text content
- 在角落添加 title blocks 或 stamps
- 使用 gradients 或 glossy effects
- 添加 slide numbers、footers 或 logos

## Best For

Technical explanations、concept breakdowns、academic presentations、knowledge documentation、research summaries、educational content with depth、bilingual audiences
