# chalkboard

黑色 chalkboard background，搭配彩色 chalk drawing style

## Design Aesthetic

Classic classroom chalkboard aesthetic，搭配 hand-drawn chalk illustrations。带 nostalgic educational feel，使用不完美、sketchy lines 捕捉传统教学的温度。彩色 chalk 创建 visual hierarchy，同时保持真实 chalkboard experience。

## Background

- Color: Chalkboard Black (#1A1A1A) 或 Dark Green-Black (#1C2B1C)
- Texture: Realistic chalkboard texture，包含细微 scratches、dust particles 和 faint eraser marks

## Typography

### Primary Font (Headlines)

Hand-drawn chalk lettering style。Bold、略不均匀的 strokes，带可见 chalk texture。不完美 baseline 增加真实感。强调时使用 white 或 bright colored chalk。

### Secondary Font (Body)

更整洁的 chalk handwriting，以保证可读性。Sizing 一致但带自然变化。Light chalk texture，strokes 比 headlines 更细。

## Visual Elements

- 使用 sketchy、imperfect lines 的 hand-drawn chalk illustrations
- text 和 key elements 周围添加 chalk dust effects
- Doodles：stars、arrows、underlines、circles、checkmarks
- Mathematical formulas 和 simple diagrams
- Eraser smudges 与 chalk residue textures
- Wooden frame border 可选
- Stick figures 和 simple icons
- 带 hand-drawn feel 的 connection lines

## Style Rules

### Do

- 所有元素保持 authentic chalk texture
- 全篇使用 imperfect、hand-drawn quality
- 添加细腻 chalk dust 和 smudge effects
- 用 color variety 创建 visual hierarchy
- 包含 playful doodles 和 annotations

### Don't

- 使用完美 geometric shapes
- 创建干净到像 digital-looking 的 lines
- 添加 photorealistic elements
- 使用 gradients 或 glossy effects
- 添加 slide numbers、footers 或 logos

## Best For

Educational presentations、classroom content、tutorials、teaching materials、back-to-school themes、workshop presentations、informal learning sessions、knowledge sharing
