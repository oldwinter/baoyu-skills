# notion

带 clean data focus 和 productivity tool styling 的 SaaS dashboard aesthetic

## Design Aesthetic

Clean、functional SaaS interface aesthetic。Dashboard-inspired layouts，带清晰 data hierarchy。Notion、Linear 和 modern productivity tool styling。Information-dense 但 organized。Professional 且 trustworthy。

## Background

- Color: Light Gray (#F7F7F5) 或 Pure White (#FFFFFF)
- Texture: 无；clean solid backgrounds

## Typography

### Primary Font (Headlines)

System UI stack 或 Inter。Semi-bold weight 用于 emphasis。Clean、functional letterforms。Letter-spacing 略紧。

### Secondary Font (Body)

同一字体家族，regular weight。针对 screen reading 优化。舒适 line height（1.5-1.6）。

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | Light Gray | #F7F7F5 | Primary background |
| Card Background | Pure White | #FFFFFF | Content cards |
| Primary Text | Near Black | #1F1F1F | Headlines、body |
| Secondary Text | Gray | #6B6B6B | Metadata、labels |
| Border | Light Border | #E5E5E5 | Card borders、dividers |
| Accent Blue | Notion Blue | #2383E2 | Links、primary actions |

| Accent Yellow | Warning | #DFAB01 | Cautions |

## Visual Elements

- 带 subtle borders 或 shadows 的 card-based layouts
- Clean data tables 和 charts
- Progress bars 和 metric displays
- Icon-based navigation hints
- Checkbox 和 toggle styling
- Tag 和 label chips
- Subtle hover state styling
- Breadcrumb 和 hierarchy indicators

## Style Rules

### Do

- 使用 card-based content organization
- 创建清晰 data hierarchy
- 使用 subtle shadows 和 borders
- 保持 layouts grid-aligned
- 突出展示 metrics

### Don't

- 使用 decorative illustrations
- 添加 gradients 或 complex backgrounds
- 创建 artistic layouts
- 使用 rounded blob shapes
- 添加 slide numbers、footers 或 logos

## Best For

Product demos、SaaS presentations、productivity tool pitches、metrics dashboards、feature walkthroughs、B2B presentations、technical product marketing
