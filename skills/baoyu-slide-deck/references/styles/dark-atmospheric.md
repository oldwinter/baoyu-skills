# dark-atmospheric

使用 deep colors 和 glowing accent elements 的 dark moody aesthetic

## Design Aesthetic

Cinematic dark mode aesthetic，带 atmospheric depth。Deep purples、blacks 和 rich shadows 搭配 glowing accents，创造 dramatic visual contrast。神秘、精致且视觉冲击强。非常适合 evening events、creative industries 和 premium brand presentations。

## Background

- Color: Deep Purple-Black (#0D0D1A) 或 Rich Navy (#1A1A2E)
- Texture: 从较暗边缘到略亮中心的 subtle gradient，带 atmospheric fog effect

## Typography

### Primary Font (Headlines)

使用 light/white 的 elegant serif 或 refined sans-serif。与 dark background 形成高对比。Medium 到 bold weight。Letterforms 可带 subtle glow effect。

### Secondary Font (Body)

使用 light gray 或 muted white 的 clean sans-serif。在 dark backgrounds 上可读。Regular weight，line height 宽松。

## Visual Elements

- Glowing accent elements 和 borders
- Subtle gradient backgrounds
- Atmospheric fog 或 particle effects
- Key elements 上使用 neon-style highlights
- 带 backlit edges 的 silhouettes
- Audio waveforms 或 sound visualizations
- Radiating light circles 和 orbs
- Cinematic letterboxing 可选

## Style Rules

### Do

- 保持 high contrast 以确保可读性
- 谨慎使用 glowing effects 来强调
- 用 gradients 创建 atmospheric depth
- 设计 dramatic visual focal points
- 在 dark backgrounds 上保持 text crisp

### Don't

- 过度使用 neon effects（less is more）
- 创建 low-contrast text combinations
- 使用 bright backgrounds
- 添加 cluttered busy elements
- 添加 slide numbers、footers 或 logos

## Best For

Entertainment presentations、music and audio content、creative agency pitches、evening events、premium brand reveals、gaming content、cinematic storytelling、tech product launches
