# pixel-art

带 nostalgic gaming visual style 的 retro 8-bit pixel art aesthetic

## Design Aesthetic

Pixelated retro aesthetic，让人联想到 classic 8-bit 和 16-bit era games。Chunky pixels、limited color palettes 和 nostalgic gaming references。Simple geometric shapes 以 blocky pixel form 渲染。Fun、playful 且一眼可识别的 retro tech aesthetic。

## Background

- Color: Light Blue (#87CEEB) 或 Soft Lavender (#E6E6FA)
- Texture: Subtle pixel grid pattern，CRT scanline effect 可选

## Typography

### Primary Font (Headlines)

Pixelated bitmap font style。Chunky、blocky letterforms，带 visible pixel structure。All caps 以最大化可读性。渲染为真实 pixel art，而不是 smooth vectors。

### Secondary Font (Body)

较小 pixel font，使用一致 8x8 或 16x16 character grid。与 background 高对比。限制 anti-aliasing 以保持 retro feel。

## Visual Elements

- 所有元素渲染为 visible pixel structure
- Simple iconography：notepad、checkboxes、gears、rockets、play buttons
- 带 pixel borders 的 text bubbles 和 speech boxes
- 8-bit style decorative elements：stars、hearts、arrows
- 带 chunky pixel segments 的 progress bars
- 用于 gradients 和 shadows 的 dithering patterns
- 每张 slide 限制在 16-32 color palette

## Style Rules

### Do

- 全篇保持一致 pixel grid
- 使用 limited color palette（最多 16-32 colors）
- 创建 blocky、geometric shapes
- 在合适处添加 nostalgic gaming references
- 使用 dithering 处理 color transitions

### Don't

- 使用 smooth gradients 或 anti-aliasing
- 创建 photorealistic elements
- 使用 thin lines 或 fine details
- 添加 modern glossy effects
- 添加 slide numbers、footers 或 logos

## Best For

Gaming presentations、tech tutorials、nostalgic content、developer talks、retro-themed events、educational content for younger audiences、creative tech presentations
