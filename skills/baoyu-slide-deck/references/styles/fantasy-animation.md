# fantasy-animation

受 classic fantasy illustration 启发的 whimsical hand-drawn animation style

## Design Aesthetic

Charming hand-drawn animation aesthetic，让人联想到 classic Disney、Studio Ghibli 或 European storybook illustration。Soft、painterly textures 搭配 warm、inviting colors。Friendly characters、magical elements 和 storybook layouts。Enchanting、nostalgic 且 emotionally engaging。

## Background

- Color: Soft Sky Blue (#E8F4FC) 或 Warm Cream (#FFF8E7)
- Texture: Subtle watercolor wash、soft brush strokes、gentle paper texture

## Typography

### Primary Font (Headlines)

Whimsical serif 或 decorative hand-lettered style。轻微 curvature 和 organic feel。Warm、friendly character。想象 fairy tale book titles。

### Secondary Font (Body)

Rounded sans-serif 或 casual handwritten style。Friendly 且 readable。在保持 storybook aesthetic 的同时保持清晰可读。

## Visual Elements

- Central illustrated character（friendly、expressive）
- Small companion creatures（animals、magical beings）
- Storybook-style environment backgrounds
- Magical floating objects（books、bags、boxes、orbs）
- Decorative elements：stars、sparkles、flowers、leaves
- Soft shadows 和 gentle highlights
- 通过 foreground/background elements 创建 layered depth
- Themed content containers（trunks、satchels、scroll boxes）

## Style Rules

### Do

- 创建 warm、inviting compositions
- 使用 soft edges 和 painterly textures
- 包含 charming character illustrations
- 添加 magical decorative touches
- 保持 storybook narrative feel

### Don't

- 使用 harsh geometric shapes
- 创建 dark 或 intimidating imagery
- 添加 photorealistic elements
- 使用 cold color palettes
- 添加 slide numbers、footers 或 logos

## Best For

Educational content、children's presentations、storytelling、creative workshops、book presentations、fantasy/gaming content、inspirational talks、family-friendly events
