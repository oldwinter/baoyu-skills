# minimal

最大 whitespace 和 zen-like simplicity 的 ultra-clean keynote style

## Design Aesthetic

Maximum whitespace，元素最少。Zen-like simplicity，每个元素都必须有存在理由。Premium、refined aesthetic，适合 executive audiences。Less is more；持续移除，直到再也无物可删。

## Background

- Color: Pure White (#FFFFFF)
- Texture: 无；absolute clean，没有 grain 或 patterns

## Typography

### Primary Font (Headlines)

Clean geometric sans-serif，如 SF Pro Display、Inter 或 Helvetica Neue。Light 到 medium weight，带 elegant restraint。Generous letter-spacing。用 large scale 形成 impact，但不依赖 boldness。

### Secondary Font (Body)

与 headlines 使用同一字体家族，但 weight 更轻。Size contrast 最小。全篇 clean、airy。

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | Pure White | #FFFFFF | Primary background |
| Primary Text | Near Black | #1A1A1A | Headlines、body |
| Secondary Text | Medium Gray | #6B7280 | Captions、metadata |
| Accent | Single Brand Color | #2563EB | 只使用一个 accent，且克制 |
| Dividers | Light Gray | #E5E7EB | Subtle separators |

## Visual Elements

- 克制使用 single accent color
- 使用 thin hairline rules 做分隔
- Generous margins（四周最少 15%）
- Center 或 left-aligned layouts
- 只有必要时才使用 simple geometric shapes
- 不使用 decorative elements
- Data visualizations 使用 single color 或 grayscale

## Style Rules

### Do

- 将 empty space 作为 design element
- 只使用 single accent color
- 保持 text minimal（每张 slide 10 个词以内）
- 在元素之间创造 breathing room
- 用 scale 创建 hierarchy

### Don't

- 用 decoration 填满 empty space
- 使用多个 accent colors
- 添加非必要 icons 或 illustrations
- 创建 dense information layouts
- 添加 slide numbers、footers 或 logos

## Best For

Executive briefings、keynote presentations、premium brand communications、minimalist products、investor meetings、high-level strategy
