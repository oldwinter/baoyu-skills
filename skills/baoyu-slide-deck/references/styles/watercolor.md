# watercolor

带 hand-painted textures 和 natural warmth 的 soft watercolor illustration style

## Design Aesthetic

Gentle watercolor aesthetic，带 visible brush strokes 和 natural color bleeding。Hand-painted feel，使用 soft edges 与 organic shapes。Warm、approachable 且 artistically refined。将 artistic expression 与清晰 information delivery 结合。

## Background

- Color: Warm Off-White (#FAF8F0) 或 Soft Cream (#FFF9E6)
- Texture: 细腻 watercolor paper texture，带 visible grain

## Typography

### Primary Font (Headlines)

Titles 使用 elegant handwritten 或 brush script。Organic letterforms，带自然变化。Warm、personal feeling。可呈现为真实 hand-painted lettering。

### Secondary Font (Body)

Clean rounded sans-serif 或 casual handwriting style。小尺寸也可读。在保持 artistic cohesion 的同时保持功能性。

## Visual Elements

- Watercolor washes 作为 section backgrounds
- 带 visible brush strokes 的 illustrated icons
- Natural elements：leaves、bubbles、flowers
- 所有元素带 color bleeds 和 soft edges
- Hand-drawn arrows 和 connection lines
- 带 watercolor fills 的 labeled diagrams
- Small expressive character illustrations
- 克制分布 decorative nature accents

## Style Rules

### Do

- 允许 color 越过 sharp edges 自然 bleeding
- 使用 visible brush stroke textures
- 创建 soft、organic shapes
- 所有元素都包含 hand-drawn quality
- 保持 warm、inviting color palette

### Don't

- 使用 sharp geometric shapes
- 创建 hard edges 或 digital precision
- 使用 cold 或 stark colors
- 添加 photographic elements
- 添加 slide numbers、footers 或 logos

## Best For

Lifestyle content、wellness presentations、travel guides、food and cooking content、personal stories、creative workshops、artistic portfolios、warm educational content
