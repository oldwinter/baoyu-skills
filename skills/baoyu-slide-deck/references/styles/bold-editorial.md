# bold-editorial

带 bold visual expression 的 high-impact magazine editorial style

## Design Aesthetic

Magazine cover 级别的强视觉冲击。Bold typography 和 dramatic contrast。Full-bleed imagery 与 large color blocks 创造 commanding presence。每张 slide 都像 premium publication cover。

## Background

- Color: Deep Black (#0A0A0A) 为 primary，或用 Deep Blue (#0F172A) 作为 alternative
- Texture: 无；使用 clean solid backgrounds，或 pure white 搭配 bold color blocks

## Typography

### Primary Font (Headlines)

使用类似 Impact、Oswald Bold 或 Bebas Neue 的 bold condensed typeface。Oversized headlines 主导整张 slide。All-caps 带来最大冲击力。Tight letter-spacing。

### Secondary Font (Body)

使用 Inter、SF Pro 或 Helvetica Neue 等 clean sans-serif。Body text 使用 medium weight。与 background 保持高对比。

## Visual Elements

- Strong typography 本身就是 visual element
- Geometric shapes 和 bold color blocks
- Full-bleed images 或 solid color backgrounds
- High contrast gradients（subtle，不要 garish）
- Minimal decoration，让 content speak
- Dynamic diagonal lines 和 angles
- text 上使用 dramatic lighting effects

## Style Rules

### Do

- 使用 extreme scale contrast（huge headlines、small body）
- 创建 bold color block compositions
- 让 negative space 创造 tension
- 使用 full-bleed backgrounds
- 让每张 slide 都像 magazine cover

### Don't

- 使用 soft 或 muted colors
- 添加不必要 decorative elements
- 创建 busy、cluttered layouts
- 使用 thin 或 delicate typography
- 添加 slide numbers、footers 或 logos

## Best For

Product launches、marketing presentations、keynote speeches、brand showcases、investor pitches、high-stakes presentations
