# corporate

使用 navy/gold palette 和 structured layouts 的 professional business style

## Design Aesthetic

Clean lines、structured layouts 和符合 business 场景的 sophistication。传达 competence、reliability 和 institutional credibility。通过谨慎使用 whitespace 与 refined color choices，在 professionalism 和 approachability 之间取得平衡。

## Background

- Color: Pure White (#FFFFFF)，搭配 navy structural elements
- Texture: 无；以 crisp digital clarity 获得最大 professionalism

## Typography

### Primary Font (Headlines)

Modern geometric sans-serif（Inter、SF Pro 或类似字体）。Clean、professional 且高度可读。传达 competence 和 contemporary business sensibility。Medium 到 semi-bold weight。

### Secondary Font (Body)

Body text 使用 humanist sans-serif（Source Sans Pro style）。Friendly 但 professional，针对 reading comprehension 优化。Regular weight，line height 舒适。

## Visual Elements

- Clean charts 和 data visualizations
- Professional iconography（outlined style）
- Structured grid layouts
- 用于 depth 的 subtle shadows（minimal）
- Progress bars 和 metrics displays
- Organizational charts
- Timeline graphics
- Comparison tables

## Style Rules

### Do

- 保持清晰 visual hierarchy
- 使用一致 grid alignment
- 策略性应用 accent colors（gold 用于 emphasis）
- 保持 data visualizations 干净可读
- 使用 professional outlined iconography

### Don't

- 使用 playful 或 casual elements
- 应用 heavy decorative effects
- 混用过多 accent colors
- 用信息挤满 slides
- 使用 informal illustration styles
- 添加 slide numbers、footers 或 logos

## Best For

Business presentations、investor decks、quarterly reports、executive summaries、client proposals、corporate communications、board meetings
