# vector-illustration

带清晰 black outlines 和 retro soft color palette 的 flat vector illustration style

## Design Aesthetic

Flat vector illustration，不使用 gradients 或 3D effects。所有元素使用清晰、等粗 black outlines。通过 geometric simplification 将复杂对象简化为 basic shapes。Toy model aesthetic，可爱、playful 且 approachable。Panoramic horizontal compositions 效果很好。

## Background

- Color: Cream Off-White (#F5F0E6)
- Texture: 细腻 paper texture，带让人联想到 vintage prints 的 warm nostalgic feel

## Typography

### Primary Font (Headlines)

Titles 使用 large、bold retro serif，传达权威和优雅。想象 classic advertising posters。字形干净且存在感强。

### Secondary Font (Subtitles)

Colored rectangular blocks 内使用 all-caps sans-serif。呈 label-like appearance。与 block color 形成高对比。

### Body Font

使用 clean geometric sans-serif 保证可读性，如 Futura、Avenir 或类似字体。全篇 weight 一致。

## Visual Elements

- 所有 objects 都有 closed black outlines（coloring book style）
- 使用 rounded line endings，避免 sharp corners
- Trees 简化为 lollipop 或 triangle shapes
- Buildings 简化为带 grid windows 的 rectangular blocks
- 2.5D perspective（类似 isometric，但更 free-form）
- 通过 layering 和 overlap 表现 depth，而不是 atmospheric perspective
- Decorative geometric elements：radiating lines（sunbursts）、pill-shaped clouds、dots、stars
- People 画成 simple geometric figures，facial detail 极少

## Style Rules

### Do

- 全篇保持一致 outline thickness
- 使用 soft、vintage color palette
- 将所有 objects 简化为 basic geometric shapes
- 通过 layering 创建 depth
- 添加 playful decorative elements

### Don't

- 使用 gradients 或 realistic shading
- 创建 photorealistic elements
- 使用很细或变化不一的 line weights
- 包含复杂 detailed illustrations
- 添加 slide numbers、footers 或 logos

## Best For

Educational presentations、creative proposals、children's content、brand showcases、warm approachable topics、explainer content
