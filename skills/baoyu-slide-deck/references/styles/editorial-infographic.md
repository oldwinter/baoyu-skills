# editorial-infographic

带清晰 visual storytelling 的 modern magazine-style editorial infographic

## Design Aesthetic

High-quality magazine explainer aesthetic。用清晰 visual storytelling 将复杂信息转化为 digestible narratives。Clean illustrations、structured layouts 和 professional typography。想象 Wired、The Verge 或高端 science publications。

## Background

- Color: Pure White (#FFFFFF) 或 Light Gray (#F8F9FA)
- Texture: 无，或使用 subtle paper grain 营造 print feel

## Typography

### Primary Font (Headlines)

使用 bold display serif 或 modern sans-serif。Strong visual presence。Clean letterforms，带 editorial sophistication。大尺度形成 impact。

### Secondary Font (Subheads)

Section headers 使用 semi-bold sans-serif。与 body text 有清晰 hierarchy distinction。全篇 styling 一致。

### Body Font

使用为阅读优化的 humanist sans-serif。Clean、professional、accessible。舒适 line height（1.6）。

## Visual Elements

- Clean flat illustrations（不是 photos）
- Structured multi-section layouts
- 用于 key insights 的 callout boxes
- Icon-based data visualization
- 用于 abstract concepts 的 visual metaphors
- 带清晰 directional hierarchy 的 flow diagrams
- Pull quotes 和 highlight boxes
- Section dividers 和 visual breaks

## Style Rules

### Do

- 创建清晰 visual narrative flow
- 使用 structured multi-section layouts
- 包含用于 key insights 的 callout boxes
- 为 complex ideas 设计 visual metaphors
- 保持 magazine-quality polish

### Don't

- 使用 photographic imagery
- 创建 cluttered dense layouts
- 混用过多 visual styles
- 添加没有目的的 decorative elements
- 添加 slide numbers、footers 或 logos

## Best For

Technology explainers、science communication、research summaries、policy briefings、investigative content、educational deep-dives、thought leadership pieces
