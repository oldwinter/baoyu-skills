# Presentation Analysis Framework

用于创建有效 slide deck 的深度内容分析框架。

## 1. Message Hierarchy

设计 slides 前，先识别核心信息结构。

### Core Message（One Sentence）

- 最重要的单一 takeaway 是什么？
- 如果 audience 只记住一件事，它应该是什么？
- 能否用 ≤15 个词说清？

### Supporting Points（最多 3-5 个）

- 哪些 evidence 支撑 core message？
- 哪些 sub-topics 必须覆盖？
- 按 audience relevance 排序，而不是按 source 顺序

### Call-to-Action

- Audience 看完后应该做什么？
- 是否清楚、具体、可执行？
- 它出现在哪里（slide position）？

## 2. Audience Decision Matrix

| Question | Analysis |
|----------|----------|
| Who is the primary audience? | [角色、专业水平、与主题的关系] |
| What do they currently believe? | [已有知识、假设、偏见] |
| What decision do we want them to make? | [具体行动或结论] |
| What barriers exist? | [反对意见、担忧、缺失信息] |
| What evidence will convince them? | [数据类型、可信来源、情绪 hooks] |

### Audience Adaptation

| Audience Type | Content Focus | Visual Treatment |
|---------------|---------------|------------------|
| Executives | Outcomes、ROI、战略影响 | 高层次、干净、突出数据 |
| Technical | 架构、实现、specs | 详细 diagrams、code、schematics |
| General | Benefits、故事、共鸣 | 视觉隐喻、简单 charts |
| Investors | Market size、traction、team | Growth charts、milestones、comparisons |
| Learners | Step-by-step、examples、practice | Progressive reveals、exercises |

## 3. Visual Opportunity Map

识别哪些内容值得可视化。

### Content-to-Visual Mapping

| Content Type | Visual Treatment | Example |
|--------------|------------------|---------|
| Comparisons | 并排、before/after | Feature comparison table |
| Processes | Flow diagrams、编号步骤 | Workflow illustration |
| Hierarchies | Org charts、金字塔、trees | Organizational structure |
| Timelines | 水平/垂直 timelines | Project milestones |
| Statistics | Charts、highlighted numbers | Key metrics with context |
| Concepts | Icons、metaphors、illustrations | Abstract idea visualization |
| Relationships | Venn diagrams、networks | Ecosystem or dependencies |
| Lists | Structured grids、icon rows | Feature bullets with icons |

### Visual Priority

为每段内容评级：

- **Must Visualize**：复杂数据、关键差异点、值得记住的瞬间
- **Should Visualize**：支撑 evidence、次级观点
- **Text Only**：简单陈述、过渡、次要细节

## 4. Presentation Flow

为影响力和记忆留存组织结构。

### Opening（前 2-3 张）

| Element | Purpose |
|---------|---------|
| Hook | 抓住注意力（惊人统计、问题、故事） |
| Context | 说明为什么现在重要 |
| Preview | Audience 将学到/获得什么 |

### Middle（Content Slides）

| Pattern | When to Use |
|---------|-------------|
| Problem → Solution | 介绍新产品/新想法 |
| Situation → Complication → Resolution | 复杂 business cases |
| What → Why → How | 教育内容 |
| Past → Present → Future | 转型故事 |
| Claim → Evidence → Implication | 数据驱动论证 |

### Closing（最后 2-3 张）

| Element | Purpose |
|---------|---------|
| Synthesis | 回扣 core message |
| Call-to-Action | 清晰 next steps |
| Memorable Close | 有共鸣的 quote、image 或 statement |

### Transitions

- 每张 slide 都应回答："What comes next?"
- 在 sections 之间使用 narrative connectors
- 建立逻辑递进，而不是话题跳跃

## 5. Content Adaptation

决定保留、转换或省略什么。

### Keep（High Value）

- Core arguments 和 evidence
- 独特 insights 或 data
- 与 audience 相关的 examples
- 值得记住的 quotes 或 statistics

### Simplify（Medium Value）

- Technical details → Visual summaries
- 长解释 → Bullet hierarchies
- 多个 examples → 最好的 1-2 个 examples
- Background context → 简短 framing

### Visualize（Transform）

- Data tables → Charts 或 highlighted numbers
- Process descriptions → Flow diagrams
- 文字中的 comparisons → Side-by-side visuals
- Abstract concepts → Concrete metaphors

### Omit（Low Value）

- 离题信息
- 重复 examples
- 过多 caveats
- Audience 已知的背景

## 6. Analysis Checklist

创建 outline 前确认：

### Message Clarity

- [ ] Core message 已用一句话表述
- [ ] 已识别 3-5 个 supporting points
- [ ] 已定义 call-to-action

### Audience Fit

- [ ] 已识别 primary audience
- [ ] 已映射 existing beliefs
- [ ] Desired decision 清楚
- [ ] Evidence 匹配 audience needs

### Visual Planning

- [ ] 已识别关键 visualizations
- [ ] 已选择 chart/diagram types
- [ ] 已分配 visual priority

### Flow Design

- [ ] 已定义 opening hook
- [ ] 已选择 middle pattern
- [ ] 已规划 closing approach
- [ ] 已考虑 transitions

### Content Decisions

- [ ] 已应用 keep/simplify/visualize/omit
- [ ] Source material 已完整处理
- [ ] 没有遗漏重要内容
