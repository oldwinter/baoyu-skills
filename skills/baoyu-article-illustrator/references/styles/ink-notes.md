# ink-notes

纯白背景上的专业黑墨 visual notes，遵循 Mike Rohde sketchnoting 传统。

## Compared to sketch-notes

`ink-notes` 和 `sketch-notes` 是不同 styles。请选对：

| | `sketch-notes` | `ink-notes` |
|---|---|---|
| Background | 带 paper grain 的 Warm Off-White #FAF8F0 | Pure White #FFFFFF，干净，无 texture |
| Palette | 柔和暖色 accents（orange, mustard, sage, light blue） | 黑墨为主 + 少量语义强调色 |
| Feel | 柔和、温暖、教育感、亲近 | 专业、结构化、whiteboard-presentation |
| Best For | 友好教程、onboarding、轻松解释 | Before/After essays、tech manifestos、framework analogies |

拿不准时：温暖友好 → `sketch-notes`。克制专业 → `ink-notes`。

## Design Aesthetic

克制的手绘 visual note。自信的黑色墨线带轻微晃动，hand-lettered typography，只用少量颜色做语义强调。感觉像熟练 visual notetaker 的 whiteboard presentation：干净、结构化、刻意手绘，而不是装饰性涂鸦。

## Background

- Color: Pure White (#FFFFFF)
- Texture: 干净，无 grain，无 tint

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | Pure White | #FFFFFF | Canvas |
| Primary Ink | Near Black | #1A1A1A | 所有 lines、text、figures、arrows |
| Accent Warm | Coral Red | #E8655A | Risk、problem、gap、emphasis |
| Accent Cool | Muted Teal | #5FA8A8 | Positive、solution、"after" state |
| Accent Neutral | Dusty Lavender | #9B8AB5 | Neutral tags、category labels |
| Soft Fill | Pale Gray | #F0F0F0 | 细微 zone backgrounds（可选） |

Color accents 必须少于画布面积 10%，且只承载语义。结构工作由黑色墨线完成。

## Visual Elements

- 所有 strokes 都使用带刻意轻微晃动的黑墨线
- Hand-lettered titles（粗体、偏大）和 handwritten body annotations
- 简单 stick-figure characters，姿态有表现力（pointing、thinking、walking）
- 角色上方的 role labels（例如 "Tech Lead", "Compliance Officer"）
- 手绘轮廓的 thought bubbles 和 speech bubbles
- 用于内容分组的圆角矩形 frames
- 用于 placeholder、"coming next" 或 empty states 的虚线边框矩形
- 带小 inline labels 的曲线手绘 arrows
- Comparison zones 之间的垂直或水平 dividers（"Before" | "After"）
- 桥接两个 zones 的 "Mindset shift" curved arrow
- Bottom tagline：单行 hand-lettered conclusion，点明 takeaway
- Stars、asterisks、underlines 用于强调，少量使用

## Style Rules

### Do

- 背景保持纯白，无 texture 或 tint
- 让黑墨主导 outlines、text 和 figures
- 只用 accent colors 做语义高亮
- 所有 type 都保持 hand-lettered，不用 computer-generated fonts
- 保持自信线条质量（wobble，但不要 messy）
- 底部包含总结 main takeaway 的 tagline
- 用清晰 zones 和可见 dividers 组织内容
- 对 future、empty 或 placeholder states 使用 dashed boxes

### Don't

- 使用暖 off-white 或纸质纹理背景（那是 sketch-notes 的领域）
- 大面积填充色块
- 每张图使用超过 3 种 accent colors
- 使用完美几何形；保留手绘 wobble
- 用装饰 doodles 造成杂乱；每个元素都必须有意义
- 使用 gradients、shadows 或 computer-generated fonts

## Type Compatibility

| Type | Rating | Notes |
|------|--------|-------|
| comparison | ✓✓ | 最适合 Before/After、Traditional vs New、side-by-side contrasts |
| framework | ✓✓ | OS-style command centers、layered architectures、organizational models |
| flowchart | ✓✓ | 带 labeled stages 的 process explainers、workforce pipelines |
| infographic | ✓ | Multi-zone technical summaries、manifesto-style posters |
| timeline | ✓ | 带 era markers 和 milestones 的手绘水平 arrow |
| scene | ✗ | 不推荐，缺少 scenic space |

## Best For

Product and engineering essays、tech manifestos、framework introductions、Before/After narratives、OS-level comparisons、workforce and organizational analogies、talks 的 visual summaries、thought-leadership articles
