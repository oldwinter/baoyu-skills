# screen-print

使用有限颜色、halftone textures 和符号化 storytelling 的大胆 poster art。

## Design Aesthetic

Screen print / silkscreen 美学，灵感来自 Mondo limited-edition posters 和 vintage concert prints。Flat color blocks、halftone dot patterns、粗 silhouettes，以及刻意的 print imperfections。概念化、符号化，而非字面化；一个 iconic image 讲完整故事。非常适合 opinion pieces、cultural commentary 和 editorial content。

## Background

- Color: Off-Black (#121212) 或 Warm Cream (#F5E6D0)
- Texture: 带细微 halftone dot overlay 的 paper grain

## Color Palette

| Role | Color | Hex | Usage |
|------|-------|-----|-------|
| Background | Off-Black | #121212 | Dark compositions |
| Background Alt | Warm Cream | #F5E6D0 | Light compositions |
| Primary | Burnt Orange | #E8751A | Main accent |
| Secondary | Deep Teal | #0A6E6E | Contrast accent |
| Tertiary | Crimson | #C0392B | Bold emphasis |
| Highlight | Amber | #F4A623 | Small accents |
| Text | Cream White | #FAF3E0 | On dark backgrounds |

**Duotone Pairs**（高冲击构图中选择一组）：

| Pair | Color A | Color B | Feel |
|------|---------|---------|------|
| Orange + Teal | #E8751A | #0A6E6E | Cinematic, action |
| Red + Cream | #C0392B | #F5E6D0 | Bold, classic |
| Blue + Gold | #1A3A5C | #D4A843 | Prestigious, premium |
| Crimson + Navy | #DC143C | #0D1B2A | Dramatic, noir |

**Rule**：最多使用 2-5 种颜色。颜色越少，冲击越强。

## Visual Elements

- 粗 silhouettes 和 symbolic shapes
- 色块内部的 halftone dot patterns
- 轻微 color layer misregistration（print offset effect）
- Geometric framing（circles、arches、triangles）
- Figure-ground inversion（negative space 形成 secondary image）
- Stencil-cut edges，无 outlines；形状由 color boundaries 定义
- Typography 作为设计元素融入，而不是 overlay
- Vintage poster border treatments

## Style Rules

### Do

- 限制在 2-5 种 flat colors
- 用粗 silhouettes 代替细节渲染
- 让 negative space 讲述部分故事
- 添加 halftone texture 增强真实感
- 使用 geometric composition（居中、对称）
- 参考 vintage decades（60s/70s/80s）营造时代感

### Don't

- 使用 photorealistic rendering 或 gradients
- 添加复杂面部细节（优先 silhouettes）
- 混入过多视觉元素（只保留一个 focal point）
- 使用现代 digital aesthetic
- 创建繁忙或杂乱构图
- 使用超过 5 种颜色

## Best For

Opinion/editorial articles、cultural commentary、philosophy and strategy、dramatic narratives、cinematic storytelling、music and entertainment、event announcements、bold branding content
