# hand-drawn

Sketchy、organic、personal

## Core Characteristics

Hand-drawn illustration，带 visible imperfections、organic line quality 和 personal touch。感觉像熟练艺术家的 sketchbook 或 whiteboard drawing。

## Lines

- Sketchy、organic、略不完美的 strokes
- Variable line weight（pressure points 更粗）
- Wavy connectors 和 arrows
- 可见自然手抖感

## Texture

- Paper grain 和 subtle surface texture
- Strokes 上的 pencil/pen/marker texture
- Casual fills，带 visible brush direction

## Depth

- Minimal：轻量 hand-drawn shadows 或 hatching
- 无 realistic depth 或 perspective
- 通过 overlap 做 simple layering

## Element Vocabulary

- Doodles、organic shapes、hand-lettered labels
- 带 sketchy quality 的 conceptual icons
- 带 hand-drawn wavy feel 的 connection lines
- Stars、arrows、underlines、circles、checkmarks
- Stick figures 和 simple characters

## Typography Approach

- Hand-lettered 或 marker-style text
- Bouncy baselines、organic feel
- 用 variable sizes 建立 emphasis hierarchy
