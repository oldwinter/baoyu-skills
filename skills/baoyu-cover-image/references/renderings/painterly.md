# painterly

Soft、artistic、expressive

## Core Characteristics

Watercolor 或 paint-style illustration，带 visible brush strokes、color bleeds 和 artistic texture。感觉像 hand-painted art piece。

## Lines

- Soft brush strokes，opacity 可变
- 无 hard outlines；edges 由 color transitions 定义
- Organic flowing strokes，带 natural blending

## Texture

- Visible paint 或 watercolor wash textures
- Color bleeds 和 wet-on-wet effects
- Transparent areas 透出 paper texture
- 可见 brush stroke patterns

## Depth

- Soft edges，带 natural color blending
- 通过 color fading 建立 atmospheric depth
- Layered washes 创造 depth illusion

## Element Vocabulary

- Watercolor washes 作为 backgrounds
- Natural elements：leaves、flowers、organic forms
- Soft gradients 和 color transitions
- Splatter 和 drip effects 作为 accents
- Botanical 和 environmental motifs

## Typography Approach

- Elegant brush script 或 handwritten style
- 带 brush texture 的 organic letterforms
- 与 paint environment 整合
