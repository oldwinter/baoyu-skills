# flat-vector

干净、现代、几何化 illustration。

## 核心特征

Flat design，使用干净描边、统一填充，不使用纹理或深度。可参考现代 app icon、infographic illustration 和基于 vector 的 editorial art。

## 线条

- 干净描边，stroke weight 统一
- 封闭形状（涂色书风格）
- 圆润线条端点，避免尖角
- 全程保持一致线宽

## 纹理

- 无：只使用平滑、扁平的色彩填充
- 无渐变、阴影或噪点
- 纯色色块

## 深度

- 扁平：无阴影、无透视
- 通过 2D 分层和重叠制造深度错觉
- 可选 2.5D isometric 分层（前后遮挡，无 atmospheric perspective）
- 无 3D 效果或 bevel

## 元素词汇

- 几何图标和简单形状
- 带粗描边、干净填充的对象
- 几何简化：复杂对象 → 基础形状（树 → 棒棒糖/三角形，建筑 → 矩形）
- "Toy model" 美学：可爱、圆润比例
- 装饰：圆点、线条、放射阳光、胶囊形云朵、小星星
- 干净背景上的独立元素

## Typography 方法

- 干净 sans-serif 或粗重几何 lettering
- 强可读性，一致字重
- 任意尺寸下都容易缩放
