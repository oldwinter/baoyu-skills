# screen-print

大胆、有限色的 poster art，带印刷纹理。

## 核心特征

Screen print / silkscreen 美学，使用扁平色块、halftone 纹理和刻意保留的印刷瑕疵。可参考 Mondo 限量海报、vintage 音乐会印刷品和 alternative movie poster art。

## 线条

- 色块之间边缘干净锐利
- 无描边，形状由颜色边界定义
- Stencil-cut 质感，大胆剪影
- 几何形状具备精确套准

## 纹理

- 色彩填充内使用 halftone 圆点图案
- 轻微色层套印偏差（印刷层之间有偏移）
- 色彩下方有纸张颗粒纹理
- Risograph / screen print 瑕疵（油墨扩散、网点扩大）

## 深度

- 扁平色面由前到后分层
- 通过剪影重叠和色彩分层营造深度
- 无渐变，通过 halftone 密度体现明暗变化
- Negative space 作为主动构图元素

## 元素词汇

- 大胆剪影和象征性形状
- 几何 framing（圆形、拱形、三角形）
- 图底反转（negative space 形成次级图像）
- 有限图标词汇：关键道具、象征物
- typography 作为设计元素融入，而不是覆盖层
- Vintage 海报边框处理

## Typography 方法

- 粗重 condensed sans-serif 或 hand-drawn lettering
- 受 Art Deco 影响的 vintage poster typography
- typography 是构图的整体组成部分（不是独立图层）
- 通过与背景的高对比保持强可读性
