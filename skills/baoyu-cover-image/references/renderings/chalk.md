# chalk

Educational、authentic、classroom

## Core Characteristics

Chalk on blackboard aesthetic，带 imperfect strokes、dust effects 和 authentic classroom feel。怀旧的 educational warmth。

## Lines

- Imperfect chalk strokes，pressure 可变
- Visible chalk texture 和 grain
- 略 wobbly 的 hand-drawn quality
- Thick strokes 用于 emphasis，thin strokes 用于 details

## Texture

- Text 和 elements 周围的 chalk dust effects
- Board surface（dark、slightly worn）
- Eraser smudges 和 residue
- 所有 elements 都有 grainy chalk quality

## Depth

- None：board surface 上的 flat chalk drawings
- 通过 erasure 和 redrawing 建立 layering
- 无 shadows 或 perspective

## Element Vocabulary

- Chalk doodles：stars、arrows、underlines
- Mathematical formulas 和 diagrams
- Stick figures 和 simple icons
- 带 chalk feel 的 connection lines
- Checkmarks、circles、boxes for lists
- 可选 wooden frame border

## Typography Approach

- Hand-drawn chalk lettering
- Imperfect baseline，authentic classroom feel
- White 或 bright colored chalk 用于 emphasis
- Variable sizing 建立 hierarchy
