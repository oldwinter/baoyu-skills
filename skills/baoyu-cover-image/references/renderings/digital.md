# digital

Polished、precise、modern

## Core Characteristics

Clean digital illustration，带 polished finish、precise edges 和 subtle modern effects。感觉像 professional UI mockup 或 corporate illustration。

## Lines

- Clean、precise、computer-perfect edges
- Consistent stroke weights
- 适当位置使用 sharp corners
- Anti-aliased smooth rendering

## Texture

- Smooth surfaces，无 visible texture
- 允许 subtle gradients（soft、controlled）
- Frosted glass 和 blur effects
- Clean shadows，direction 一致

## Depth

- Subtle gradients 和 soft drop shadows
- Layered card-based layouts
- Light 3D effects（subtle，不写实）
- Material Design-inspired elevation

## Element Vocabulary

- Polished icons 和 UI components
- Data visualizations：charts、graphs、metrics
- Card layouts 和 structured grids
- Tag chips、progress bars、status indicators
- Clean geometric shapes

## Typography Approach

- System UI 或 modern sans-serif（Inter、SF Pro style）
- Clean、functional、high readability
- Structured hierarchy，spacing 一致
