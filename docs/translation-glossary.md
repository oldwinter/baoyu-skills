# Translation Glossary

本文件记录中文化时复用的简短术语口径。原则：翻译自然语言说明，保留会影响运行或识别的专有名词、命令、路径、package/API/配置键和 URL。

| Source term | 中文口径 / 保留策略 |
|-------------|---------------------|
| skill / skills | 保留 `skill` / `skills`，必要时解释为“能力” |
| agent / AI agent | 保留 `agent`，必要时写作“AI agent” |
| plugin / marketplace | 保留 `plugin` / `marketplace` |
| runtime | 保留 `runtime` |
| backend | 保留 `backend`；图片生成场景用 `image backend` |
| front matter | 保留 `front matter` |
| prompt | 保留 `prompt` |
| profile / profile directory | 保留 `profile` / `profile directory` |
| CDP | 保留 `CDP` |
| EXTEND.md | 保留文件名，不翻译 |
| README / CHANGELOG / SKILL.md | 保留文件名，不翻译 |
| ClawHub / OpenClaw | 保留专有名词 |
| Codex / Claude Code / Hermes | 保留产品名 |
| X / Twitter / WeChat / Weibo / Xiaohongshu | 保留平台名；小红书可按上下文使用中文 |
| Bun / Node.js / npm / npx | 保留工具名 |
| `preferred_image_backend` 等配置键 | 保留原样 |
| CLI flags（如 `--image`、`--mode`） | 保留原样 |
| code blocks / commands / paths / URLs | 保留原样，最多翻译注释性说明 |
